# 日叶 Dayleaf：项目立项书

## 1. 项目目标

日叶是一款安静、私密、本地优先的轻量日记应用。它希望降低“开始写”的心理成本，并确保用户随时拥有自己的数据。

### 核心原则

1. **隐私默认开启**：无需账号、无分析脚本、无远程数据库。
2. **写作优先**：界面围绕时间、情绪和正文展开，不堆叠复杂功能。
3. **数据可迁移**：同时支持完整 JSON 备份和通用 Markdown 导出。
4. **离线可用**：原生 macOS 应用和 PWA 都可在断网环境继续使用。

## 2. MVP 范围

- 日记的新建、编辑、删除与自动保存
- 每日心情、标签、珍藏
- 全文搜索与珍藏筛选
- 冷启动日期主页，仅展示月历、随机写作提示和统计概览
- 可选的宽屏主页小组件：往年今日、macOS 音乐陪伴和本地呼吸计时
- 所有小组件默认关闭；外部应用联动只在用户明确开启后请求系统权限
- “日期 → 当日列表 → 编辑器”的渐进式导航，选择日期不会自动进入编辑
- 随机写作提示、换题，以及在提示下直接作答并生成日记
- 保留篇数、连续记录天数、总字数统计
- 明暗主题
- JSON 备份/恢复与 Markdown 导出
- 富文本正文、光标处表情/表情包插入与个人表情库
- 本地图片压缩、粘贴/拖放和 Openverse 开放授权素材搜索
- 2–3 秒随机引导文案开屏，并支持减少动态效果的系统设置
- 跨平台剪切、复制、粘贴、撤销、重做、搜索、新建与保存快捷键
- 响应式桌面、平板和移动端布局
- 离线缓存

## 3. 技术方案

- **形态**：原生 macOS WebKit 应用 + 静态 Web 应用 / PWA
- **语言**：原生 HTML、CSS、JavaScript ES Modules
- **数据**：浏览器 Local Storage
- **测试**：Node.js 内置测试运行器
- **依赖策略**：零运行时依赖，降低维护成本和供应链风险

## 4. 开源项目启发

本项目只学习产品思路，不复制第三方代码或视觉资源。

- [Epicenter](https://github.com/epicenter-md/epicenter)：本地优先、用户拥有数据、开放格式。
- [Memex](https://github.com/memex-lab/memex)：时间线记录、Markdown 归档和隐私优先。
- [Laverna](https://github.com/Laverna/laverna)：浏览器本地存储、加密与 Markdown 笔记体验。
- [Moodi Diary](https://github.com/ZhuJHua/moodiary)：情绪记录、多编辑方式与跨平台思路。

## 5. 后续路线

### v0.2

- IndexedDB 媒体存储，支持更多高清图片
- 单篇 Markdown 导入/导出
- 年度情绪热力图
- 可配置的写作提醒

### v0.3

- 端到端加密的可选同步
- WebAuthn / 生物识别应用锁
- 周报与月度回顾
- iCloud 或可自托管的媒体同步

## 6. 成功指标

- 首次打开 30 秒内能完成第一篇日记
- 所有核心写作流程可离线完成
- 用户可在 2 次点击内导出全部数据
- 桌面和移动端的核心流程均无阻塞
