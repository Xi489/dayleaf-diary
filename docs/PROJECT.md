# 日叶 Dayleaf：项目立项书

## 1. 项目目标

日叶是一款安静、私密、本地优先的轻量日记应用。它希望降低“开始写”的心理成本，并确保用户随时拥有自己的数据。

### 核心原则

1. **隐私默认开启**：无需账号、无分析脚本、无远程数据库。
2. **写作优先**：界面围绕时间、情绪和正文展开，不堆叠复杂功能。
3. **数据可迁移**：同时支持完整 JSON 备份和通用 Markdown 导出。
4. **离线可用**：作为 PWA 安装后，可在断网环境继续使用。

## 2. MVP 范围

- 日记的新建、编辑、删除与自动保存
- 每日心情、标签、珍藏
- 全文搜索与珍藏筛选
- 月历导航与日期选择
- 篇数、连续记录天数、总字数统计
- 明暗主题
- JSON 备份/恢复与 Markdown 导出
- 响应式桌面、平板和移动端布局
- 离线缓存

## 3. 技术方案

- **形态**：静态 Web 应用 / PWA
- **语言**：原生 HTML、CSS、JavaScript ES Modules
- **数据**：浏览器 Local Storage
- **测试**：Node.js 内置测试运行器
- **依赖策略**：零运行时依赖，降低维护成本和供应链风险

## 4. 开源项目启发

本项目只学习产品思路，不复制第三方代码或视觉资源。

- [Epicenter](https://github.com/epicenter-md/epicenter)：本地优先、用户拥有数据、开放格式。
- [Memex](https://github.com/memex-lab/memex)：时间线记录、Markdown 归档和隐私优先。
- [Laverna](https://github.com/Laverna/laverna)：浏览器本地存储、加密与 Markdown 笔记体验。
- [Moodi Diary](https://github.com/ZhuJHua/moodiary)：情绪记录、多编辑方式与跨平台思路。

- 首次打开 30 秒内能完成第一篇日记

- 用户可在 2 次点击内导出全部数据
- 桌面和移动端的核心流程均无阻塞
