# 日叶 Dayleaf

一款安静、私密、本地优先的日记应用。macOS 版拥有独立原生窗口，无需浏览器、账号或后端。

## 功能

- 同一天可记录多篇日记，并分别设置心情、标签与珍藏
- 每次冷启动先进入日期主页，只呈现月历、随机写作提示和统计概览
- 按“日期 → 当日列表 → 编辑器”逐层展开；选择日期不会自动新建或打开日记
- 可在随机提示下直接作答并生成日记，也可在空白时换一个问题
- 更宽的日期主页，可按需开启“往年今日”“音乐陪伴”和“静心一分钟”小组件
- 音乐陪伴可选 Apple Music、网易云音乐或 QQ 音乐；Apple Music 支持曲名与播放控制，后两者使用无额外权限的一键打开模式
- 在光标位置插入表情和表情包，并保存最多 12 个个人表情包
- 上传、粘贴或拖放图片，也可通过图片网址插入
- 使用 Openverse 搜索开放授权的表情素材和图片
- 全文搜索、按日筛选和带篇数提示的月历导航
- 保留篇数、连续记录天数与总字数统计
- 自动保存、明暗主题与响应式布局
- 每次启动随机展示一段引导文案，并在约 2.8 秒后平滑进入主界面
- Windows/Linux `Ctrl` 与 macOS/iPad 键盘 `⌘` 快捷键，支持剪切、复制、粘贴、撤销、重做、搜索、新建和保存
- JSON 完整备份/恢复
- 通用 Markdown 导出
- 独立 macOS 应用与 PWA 离线使用

## 本地运行

需要 Node.js 18 或更高版本，不需要安装第三方依赖。

```bash
npm run dev
```

然后打开 <http://127.0.0.1:4173>。

## 独立 macOS 应用

双击项目根目录中的 `Install.command`，会自动：

1. 使用 Swift 与 WebKit 编译原生 `Dayleaf.app`
2. 将签名后的应用安装到 `~/Applications/Dayleaf.app`
3. 在桌面创建 `Dayleaf.app` 快捷方式
4. 让你以后像普通软件一样在独立窗口中使用日记

独立版不会启动浏览器、Node 服务或后台端口。关闭窗口、按 `⌘W` 或 `⌘Q` 都会先保存正在编辑的内容，再完全退出进程。窗口大小和位置会在下次打开时恢复。

常用快捷键会跟随系统习惯：macOS 和 iPad 外接键盘使用 `⌘`，Windows/Linux 使用 `Ctrl`。正文支持 `X/C/V/A/Z`，macOS 用 `⇧⌘Z` 重做，Windows/Linux 也支持 `Ctrl+Y`；`F` 或 `K` 搜索，`N` 新建日记，`S` 立即保存。macOS 原生版同时提供完整的“文件”和“编辑”菜单。

也可以手动执行：

```bash
./scripts/install_macos_shortcut.sh
open "$HOME/Applications/Dayleaf.app"
```

应用内的日记保存在 macOS WebKit 的本地数据空间。旧网页版本的数据不会自动迁移；如需迁移，请先从网页端导出 JSON，再在独立版的“备份与恢复”中导入。

主页小组件默认全部关闭。“往年今日”和“静心一分钟”完全在本机运行。“音乐陪伴”只保存开关和播放器选择，不保存或导出曲名、艺术家和播放状态。

- Apple Music：只在点击“允许并开启”后请求 macOS 自动化权限，支持当前曲目、播放/暂停和下一首。
- 网易云音乐、QQ 音乐：支持检测并打开对应应用。由于它们的 Mac 版未提供可依赖的公开曲控接口，日叶不会申请辅助功能权限、模拟键盘或使用私有系统接口。

## 检查与构建

```bash
npm test
npm run check
npm run build
npm run bundle:native
npm run build:mac
```

网页构建产物和已签名的 `Dayleaf-mac.zip` 会生成在 `dist/`。将 `.app` 保留在标准的用户应用目录，可避免 Documents 同步目录附加 Finder 元数据后影响签名校验。

## 数据与隐私

日叶没有账号、云端日记库、广告或分析脚本。日记、压缩后的图片和个人表情包保存在本机应用的 WebKit Local Storage 中；完整 JSON 备份会一并保留这些内容。只有在用户主动使用在线搜索时，搜索词才会发送给 Openverse；只有在用户主动开启 Apple Music 完整联动时，才会请求自动化权限。
