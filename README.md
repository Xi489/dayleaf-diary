# 日叶 Dayleaf

一款安静、私密、本地优先的日记应用。无需注册、无需后端，你的日记只保存在当前浏览器中。

## 功能

- 每日写作、心情、标签与珍藏
- 全文搜索和月历导航
- 连续记录天数与字数统计
- 自动保存、明暗主题与响应式布局
- JSON 完整备份/恢复
- 通用 Markdown 导出
- PWA 离线使用

## 本地运行

需要 Node.js 18 或更高版本，不需要安装第三方依赖。

```bash
npm run dev
```

然后打开 <http://127.0.0.1:4173>。

## 检查与构建

```bash
npm test
npm run check
npm run build
```

构建产物会生成在 `dist/`。

## 数据与隐私

日叶没有账号、云端数据库、广告或分析脚本。日记保存在浏览器 Local Storage 中。清除浏览器站点数据会删除日记，请定期在“备份与恢复”中导出 JSON 备份。
